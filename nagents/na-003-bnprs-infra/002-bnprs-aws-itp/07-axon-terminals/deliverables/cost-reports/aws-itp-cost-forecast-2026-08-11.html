This was almost certainly a Terraform re-apply. Disabling it again without fixing the IaC will just revert a third time — the setting has to be corrected in the module that owns these clusters, not via the CLI.

AWS Config is now $374/mo in eu-central-1 and climbing. The cause is a single recorder, wgate-uat-config-recorder — a UAT-named recorder configured with allSupported: true, includeGlobalResourceTypes: true, recordingFrequency: CONTINUOUS and recordingScope: PAID. It therefore records every configuration item across the whole region, including high-churn types (ECS::TaskDefinition, EC2::EIPAssociation, Backup::RecoveryPoint). Switching to DAILY frequency and/or excluding the churn types should recover $150–250/mo.
